HyperFrames 是 HeyGen 开源的视频渲染框架，核心理念是用写网页的方式定义视频。开发者用标准 HTML + CSS + JavaScript（GSAP 动画）编写 composition，框架通过 headless Chrome 逐帧捕获，输出 MP4/MOV/WebM。

2. 核心概念

2.1 Composition（组合）

一个 HTML 文件就是一个视频。根元素用 data-composition-id 标识，内部元素通过 data 属性控制时间轴：

<div id="root" data-composition-id="root"
     data-start="0" data-width="1920" data-height="1080">

  <video id="clip-1" data-start="0" data-duration="5"
         data-track-index="0" src="intro.mp4" muted playsinline></video>

  <h1 id="title" class="clip"
      data-start="1" data-duration="4" data-track-index="1"
      style="font-size: 72px; color: white;">
    Welcome to Hyperframes
  </h1>

  <audio id="bg-music" data-start="0" data-duration="5"
         data-track-index="2" data-volume="0.5" src="music.wav"></audio>
</div>

2.2 Clip 类型

<video>

视频片段、B-roll、A-roll

<img>

静态图片、叠加层

<audio>

音乐、音效

<div data-composition-id>

嵌套组合（动画、分组序列）

2.3 Data Attributes（时间轴控制）

属性作用
data-start元素在时间轴上的起始时间（秒）
data-duration元素持续时长
data-track-index轨道层级（类似视频编辑器的图层）
data-volume音频音量控制
data-composition-src引用外部 composition 文件
data-variable-values向子 composition 传递变量

2.4 GSAP 动画集成

HyperFrames 使用 GSAP 做动画，timeline 设为 paused: true，框架在渲染时逐帧 seek，保证帧精确：

const tl = gsap.timeline({ paused: true });
tl.to("#title", { opacity: 1, y: 0, duration: 0.5 }, 0);
tl.from("#subtitle", { opacity: 0, scale: 0.8, duration: 0.8 }, 0.3);

window.__timelines = window.__timelines || {};
window.__timelines["root"] = tl;

支持属性：opacity, x, y, scale, rotation, width, height, color, backgroundColor 等所有 CSS 可动画属性。

2.5 确定性渲染

相同输入 → 相同输出，每次都一样。引擎通过 HeadlessExperimental.beginFrame 驱动 Chrome compositor，逐帧捕获后通过 FFmpeg 编码。

3. 主要功能

🎬 Website to Video

给 AI agent 一个 URL + 创意方向，自动完成：

  1. Capture — 截图、设计 token、字体、资源
  2. Design — 品牌参考文档
  3. Script — 旁白脚本
  4. Storyboard — 分镜创意方向
  5. VO + Timing — TTS 语音 + 词级时间戳
  6. Build — 动画 HTML compositions
  7. Validate — 快照验证

🗣️ TTS 语音合成

本地运行 Kokoro-82M 模型，无需 API key：

npx hyperframes tts "Welcome to HyperFrames" --voice am_adam

支持语言：英语、西班牙语、法语、日语、中文等

📝 字幕 & 转录

本地 whisper.cpp 转录，支持导入 SRT/VTT/JSON：

npx hyperframes transcribe audio.mp3 --model medium.en

✂️ 背景移除

本地 u2net 模型，视频/图片去背景，输出透明 WebM：

npx hyperframes remove-background avatar.mp4 -o transparent.webm

🎨 Open Design

AI 生成 composition 初稿 — 配色、场景内容、GSAP 入场动画、shader 转场。下载后用 agent 精修。

🧩 Registry（组件库）

可复用的 blocks（场景）和 components（效果）：

npx hyperframes add claude-code-window
npx hyperframes add shader-wipe

命令功能

Agent-Friendly 设计：CLI 默认非交互模式，所有输入通过 flags 传递，输出纯文本，支持 --json。加 --human-friendly 启用交互 UI。

✅ HyperFrames 优势

  • LLM 生成质量更高（HTML 训练数据丰富）
  • 零构建步骤，一个 HTML 文件即可
  • GSAP 帧精确，不会时间漂移
  • Apache 2.0 完全免费商用
  • 可视化编辑器天然适配
  • 任意网页内容可直接复用

⚠️ HyperFrames 不足

  • 无分布式渲染（长视频性能受限）
  • 项目较新，社区生态还在建设
  • 不适合已有 React 组件库的团队复用
  • 文档和示例还在快速迭代中

8. 总结评估

适合谁？

  • AI 视频自动化 — 用 agent 批量生产营销视频、社交内容
  • 前端开发者 — 已有 HTML/CSS/GSAP 技能，零学习成本
  • SaaS 产品 — 需要 programmatic video generation 的平台
  • 内容创作者 — 快速从网站/品牌素材生成宣传视频
  • 开源项目 — Apache 2.0 无商用限制

关键判断

成熟度早期但可用（v0.1.x），HeyGen 内部生产使用
社区热度GitHub 9.5k+ stars，增长迅速
技术赌注HTML > React 作为视频编写层（对 AI 时代正确）
商业模式开源框架 + HeyGen 平台商业化
风险单机渲染限制、生态早期、依赖 HeyGen 持续投入

💡 对 Dale 的价值

如果你的 side project 需要自动生成产品宣传视频（比如给 Amazon 产品做短视频广告），HyperFrames + AI agent 是目前最低成本的方案。用 HTML 定义模板，agent 填充内容，CLI 批量渲染。完全本地运行，无 API 费用（除 TTS 外）。

但如果只是偶尔做视频，直接用 HeyGen 平台可能更省事。HyperFrames 的价值在规模化、自动化、可编程。
