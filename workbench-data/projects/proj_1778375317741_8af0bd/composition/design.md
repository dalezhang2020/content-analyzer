# Linear — Product Launch Video Design

## Brand Colors

| Role | Hex | Usage |
|------|-----|-------|
| Background | #08090A | Primary dark background |
| Surface | #121314 | Cards, elevated surfaces |
| Text Primary | #F7F8F8 | Headlines, primary text |
| Text Secondary | #8A8F98 | Body text, descriptions |
| Text Tertiary | #62666D | Subtle labels |
| Accent Purple | #5E6AD2 | Brand accent, CTAs |
| Accent Blue | #B2D5FF | Highlight, glow |
| Accent Lavender | #DFD1FF | Secondary highlight |
| Border | #23252A | Subtle borders |
| White | #FFFFFF | Pure white for emphasis |

## Typography

- **Headlines**: Inter Variable, weight 510, tracking -0.02em
- **Body**: Inter Variable, weight 400
- **Mono**: Berkeley Mono, weight 400

## Motion

- Apple keynote energy: slow reveals, confident holds, minimal but impactful
- Easing: power3.out for entrances, power2.inOut for subtle shifts
- No bounce, no elastic — smooth and deliberate

## Constraints

- Dark mode only
- Minimal UI chrome
- Let content breathe — generous whitespace
- No gradients on large surfaces (banding risk)
